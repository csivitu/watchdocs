# WatchDocs

WatchDocs is a VS Code extension designed to streamline development by automatically detecting project dependencies and providing instant access to their official documentation.

## Current Project Status

Currently, the extension is in its initial setup phase with the following features implemented:
- **Activity Bar Integration**: A dedicated WatchDocs icon in the VS Code Activity Bar.
- **Project Docs Sidebar**: A sidebar view that lists project dependencies (currently displaying mock data like React and Express).
- **Documentation Shortcuts**: Interactive tree items that allow users to jump directly to official dependency documentation in their browser.
- **Scan Command**: A base `Scan Dependencies` command framework initiated for future automated dependency discovery.

The project is currently serving as a functional prototype for the UI and sidebar navigation components.
